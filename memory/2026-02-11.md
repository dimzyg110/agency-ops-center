### Key Technical Learnings
- **Railway monorepo issue**: Single `railway.toml` at root applies to all services by default
- **Service-specific config**: Can override with service-specific `railway.toml` in subdirectories
- **Vite env var naming**: Must use `VITE_` prefix, not `NEXT_PUBLIC_` (Next.js convention)
- **Dockerfile ARG/ENV**: Build-time vars need both ARG and ENV declarations for Vite to pick them up
- **Railway CLI auth**: Browserless mode works in Docker containers via pairing code flow
