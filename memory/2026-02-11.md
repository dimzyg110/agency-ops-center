### Key Lessons Learned
1. **Never say "deployed" without E2E testing** - Randy was right to push back
2. **Database conflicts:** When existing tables exist, just drop them - don't overthink schema isolation
3. **Clerk routing:** path-based routing causes redirect loops with React Router - use hash routing
4. **Railway has network restrictions** from sandbox - use Railway CLI or Railway service context for DB access
5. **Wrong `codex` binary:** `/usr/local/bin/codex` is a blog tool, not OpenAI Codex CLI
6. **Multiple Railway projects:** Always verify which project is linked before claiming deployment success
7. **Testing is mandatory:** Spawn Playwright agents to verify actual user flows, don't assume it works
