- CamoFox Fission (site isolation) actually BREAKS cross-origin `page.evaluate(fetch())` 
- PRs #18-#28 were all wasted trying to fix CamoFox — the real fix is removing it entirely

## Key Lessons Learned Today
1. **Investigate before implementing**: Proper flow = investigator → findings doc → implementer with findings. Small "quick fixes" wasted 6+ PRs.

3. **CamoFox Fission breaks scraping**: Site isolation prevents cross-origin page.evaluate(fetch()). Anti-detection features can hurt more than help.
4. **Plain Playwright Firefox IS enough**: 197K+ prices scraped without any anti-detection. Realistic viewport/UA/locale settings suffice.
5. **COO must direct, not just coordinate**: When approach fails 6+ times, stop retrying — step back and direct Opus to build the right solution.
6. **Always cleanup subagent sessions**: `cleanup: "delete"` prevents dashboard clutter and gateway instability.
7. **OpenClaw contextTokens is global only**: No per-agent override in current schema. Feature request opportunity.
