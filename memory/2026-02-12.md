    - Fix: Codex 5.3 added manual JWT verification using `jose` library (Clerk transitive dep). Verifies Bearer token against Clerk's JWKS endpoint (`https://humane-dinosaur-0.clerk.accounts.dev/.well-known/jwks.json`). Commit `f86397f`.

    - BUT: `jose` library was not a direct dependency — it's a transitive dep of `@clerk/fastify` and wasn't available at runtime in Docker prod stage. Deploy kept FAILING (TypeScript compiled fine but runtime crash).
    - **Fix v2**: Replaced `jose` with Node's built-in `crypto` module for JWT verification. Manual JWKS fetch + cache (1hr), RS256 signature verification via `crypto.createVerify('RSA-SHA256')`. Zero external deps. Commit `b3f78b8`.
    - Also hit TypeScript error on `AuthObject.userId` — `@clerk/fastify` v2 types don't expose `.userId` directly. Fixed by casting to `ClaimsRecord` and checking `userId ?? id ?? subject`. Commit `883f327`.
