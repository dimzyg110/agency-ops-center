# Budtender Cheat Sheet

**Purpose:** Pocket-sized cards with 3 key selling points per strain. Budtenders keep these behind the counter.

---

## FORMAT

**Size:** Business card (3.5" x 2") or playing card (2.5" x 3.5")
**Material:** Thick cardstock, matte or soft-touch finish
**Style:** One strain per card, collectible feel

---

## CARD TEMPLATE

### Front

```
┌─────────────────────────────────┐
│                                 │
│  [STRAIN NAME]                  │
│  [Indica / Sativa / Hybrid]     │
│                                 │
│  THC: XX%  |  [Terp Profile]    │
│                                 │
│  [AC LOGO - small, bottom]      │
│                                 │
└─────────────────────────────────┘
```

### Back

```
┌─────────────────────────────────┐
│                                 │
│  SELL IT IN 3 POINTS:           │
│                                 │
│  1. [Flavor/Smell hook]         │
│                                 │
│  2. [Effect/Feeling]            │
│                                 │
│  3. [Who it's for]              │
│                                 │
│  "Quick line to close"          │
│                                 │
└─────────────────────────────────┘
```

## DESIGN NOTES

### Colors
- Background: Black or dark charcoal
- Text: White + Gold accents
- Strain name: Gold
- AC logo: Gold or white

### Typography
- Strain name: Bold, prominent
- Selling points: Clean, readable at a glance
- Quick close: Italicized or quoted

### Production
- Print in sets (1 of each strain)
- Rubber band or small box to hold set
- Could include blank "notes" card for budtenders to add their own thoughts

### Distribution
- Give to budtenders during staff meal/onboarding
- Replace with updated versions when new strains drop
- Encourage them to keep in apron pocket

---

## NOTES

- Keep points SHORT - budtenders scan these mid-conversation
- "For" section should paint a customer picture
- Quick close should feel natural, not salesy
- Update THC/terps when COAs change
- **NEED:** Terp profiles from COAs to complete cards
