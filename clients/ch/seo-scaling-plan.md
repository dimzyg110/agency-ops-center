## Phase 0: Emergency Fixes (Week 1)

_Cost: $0 | Impact: Immediate_

These are blocking everything. Do them before anything else.

### 1. Set Up Conversion Tracking

Zero key events in GA4 means we can't measure anything. Set up:

- **"Get Directions" clicks** → key event
- **"Order Now" (Dutchie) clicks** → key event
- **Phone calls** → key event
- **Flight Club signups** → key event
- **Flight Kit page views** → key event

### 2. Claim Google Search Console

- Verify `cannabishealingllc.com` in GSC
- Submit XML sitemap
- Start tracking impressions, clicks, and keyword positions
- _This is the single most important SEO tool and it's free_

### 3. Fix Page Speed

- 23.6s average engagement = people are bouncing
- Audit Core Web Vitals (LCP, CLS, FID)
- Compress hero video, lazy-load images, minimize JS bundles

### 4. Quick-Fix Title Tags & Meta Descriptions

Every page should follow this format:

```
Homepage: "Cannabis Healing | Dispensary 5 Min from Logan Airport | East Boston"

Shop:     "Shop Cannabis | Flower, Edibles, Vapes | Cannabis Healing East Boston"
```

## Phase 2: Google Business Profile Domination (Weeks 2-6)

_Cost: ~$0-200 | Impact: 2-8 weeks_

GBP is the single biggest lever for local cannabis SEO. BOUTIQ has 750+ reviews at 4.9 stars. This is the mountain to climb.

### GBP Optimization Checklist

- [ ] Primary category: **Cannabis Store**
- [ ] Secondary: Marijuana Dispensary, Herbal Medicine Store
- [ ] Description updated with "5 minutes from Logan Airport" + Flight Kit mention
- [ ] All attributes enabled (parking, accessibility, debit, LGBTQ+ friendly)
- [ ] 20+ photos uploaded (exterior, interior, products, Flight Kits, staff, parking)
- [ ] Hours verified and accurate
- [ ] Q&A seeded with 10+ pre-answered questions
- [ ] Products added to GBP product catalog

### Review Generation Engine

**Target: 50 reviews in 60 days → 150 in 6 months → 500+ in 12 months**

| Tactic                  | Implementation                                                                 | Expected Volume   |
| ----------------------- | ------------------------------------------------------------------------------ | ----------------- |
| **Post-purchase SMS**   | Alpine IQ automation — 2 hours after purchase, send review link                | 5-10/week         |
| **QR code at checkout** | Physical card: "Loved your visit? Leave us a review" → direct Google link      | 3-5/week          |
| **Flight Kit insert**   | Small card inside every kit: "How was your Flight Kit?" → review link          | 2-3/week          |
| **Staff ask**           | Train budtenders: "If you enjoyed your visit, a Google review really helps us" | 2-5/week          |
| **Review response**     | Respond to EVERY review within 24 hours with keyword-rich replies              | Signals to Google |

**Keyword-rich review responses:**

> "Thanks for stopping by our dispensary near Logan Airport! Glad the Flight Kit made your trip easier. See you next time you land in Boston! 🛬"

### AI Search Optimization (New Channel)

CH is already getting traffic from ChatGPT (3 sessions). This is a growing channel.

To rank in AI-generated answers:

- Create clear, factual, well-structured content that AI can cite
- Answer questions directly in H2/H3 format
- Use FAQ schema markup (helps both Google and AI)
- Ensure NAP data is consistent (AI pulls from multiple sources)
- Target question-based keywords: "Where is the closest dispensary to Logan Airport?"
