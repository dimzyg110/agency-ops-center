# New Project Pipeline Skill

Use this skill when Randy has a new project idea or when a strategic opportunity is identified.

## When to Use

- Randy says "I have an idea for..." or "What if we built..."
- A strategic opportunity surfaces from research or client work
- An existing experimental project needs to be formalized

## How to Use

1. Read `WORKFLOW.md` in this directory for the full pipeline
2. Start at Phase 1 (Idea Capture) and progress through each phase
3. Each phase has a quality gate — projects that don't pass get killed
4. Only quality projects survive to `projects/internal/`

## Key Principles

- **We only build quality shit** — conviction ≥ 7 or kill it
- **Multi-agent validation** — different models = diverse perspectives
- **Randy approves at every gate** — no autonomous promotion
- **Iterate** — work happens in sprints, not waterfalls
- **Revenue-first** — if it doesn't have a clear path to money, it dies
