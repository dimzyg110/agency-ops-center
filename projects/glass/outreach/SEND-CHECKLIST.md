# GLASS Outreach — Sending Checklist

## Pre-Send Verification Steps

### 1. Data Validation
- [ ] Confirm all pricing data is from most recent menu scrape (within 7 days)
- [ ] Verify product counts match current database
- [ ] Check that pending license application numbers are current

### 2. Report Card URLs
- [ ] Verify each `glassintel.xyz/report/[slug]` URL is live and accessible
- [ ] Confirm URL slugs match the exact store naming convention in the database
- [ ] Test redirect chains (if using redirects) to ensure they land on correct report
- [ ] **Critical:** Broken links will undermine credibility — do not send until all verified

### 3. Email Configuration
- [ ] Verify sender email: `randy@roviqai.xyz` (not roviq.ai)
- [ ] Confirm Reply-To is set correctly
- [ ] Check that all URLs use `roviqai.xyz` domain (not roviq.ai)
- [ ] Test email rendering in both desktop and mobile views

### 4. Recipient Verification
- [ ] Confirm email addresses are current (no bounces in prior sends)
- [ ] Verify recipient names match correctly (e.g., "Bobby" not "Bob" if that's their preference)
- [ ] For duplicate recipients (CNA, Pioneer Valley), confirm send order

### 5. Legal/Compliance
- [ ] Confirm CAN-SPAM compliance (physical address in footer)
- [ ] Verify unsubscribe link is functional
- [ ] Ensure no misleading claims in pricing data

## Recommended Send Time

### Optimal Window: 9:00 AM — 11:00 AM ET

**Why this window:**
- Operators typically review emails in the morning before opening
- Catches them before lunch meetings or busy opening hours
- Higher open rates than afternoon/evening sends

### Day of Week Recommendations
- **Tuesday-Thursday** are optimal (avoid Monday rush, Friday weekend prep)
- Avoid sending the week of major holidays

### Sending Sequence
1. **First batch (Day 1):** High-priority targets with strongest data stories
   - #3 Haven Center (61% preroll premium)
   - #9 New Dia (72% prerolls)
   - #12 DDM Cannabis (40-point spread)
   
2. **Second batch (Day 2):** Unique-insight and cross-location emails
   - #5 CNA Amesbury (compares to own Haverhill)
   - #10 Caroline's (covers both locations)
   
3. **Third batch (Day 3+):** Standard sends
   - Remaining 19 emails, 2-3 per day to avoid spam flags

## What to Track

### Primary Metrics

| Metric | Target Benchmark | Why It Matters |
|--------|-----------------|----------------|
| **Open Rate** | 35-45% | Indicates subject line effectiveness |
| **Click-Through Rate (CTR)** | 8-12% | Shows email engagement with data |
| **Report Card Page Views** | 15-20% of opens | CTA effectiveness |
| **Report Card Signups** | 3-5% of views | Actual conversion to lead |

### Secondary Metrics

| Metric | What to Monitor |
|--------|-----------------|
| **Reply Rate** | >2% is strong — indicates data value |
| **Unsubscribe Rate** | Should be <0.5% |
| **Bounce Rate** | Should be <2% |
| **Link Clicks by Category** | Which pricing insights attract most interest |

### Tracking Setup
- [ ] UTM parameters on all report card links: `?utm_source=outreach&utm_medium=email&utm_campaign=batch1`
- [ ] Unique tracking domains or parameters per email variant (Subject A vs B)
- [ ] Google Analytics goal tracking for report card signups
- [ ] Email platform click tracking enabled

## Follow-Up Timing

### Initial Follow-Up Window: 5-7 Days After First Send

**Follow-Up Criteria:**
- [ ] Did not open initial email → Send Subject B variant
- [ ] Opened but did not click → Send with different angle (e.g., competitor focus)
- [ ] Clicked report card → Do NOT follow up immediately (they're evaluating)

### Follow-Up Email Templates

**If no open:**
```
Subject: Quick correction on [Store Name] data

Hey [Name],

Sent this earlier this week — wanted to make sure it didn't land in spam.

[Link to report card]

— Randy
```

**If opened, no click:**
```
Subject: One more thing on [Store Name] pricing

Hey [Name],

Wanted to add one more data point that didn't make the first email:

[One additional insight]

[Link to report card]

— Randy
```

### Dead Lead Criteria
- No open after 2 emails (Subject A + Subject B)
- No response after 3 total touchpoints
- Mark as "not interested" in CRM

### Long-Term Nurture
- Add to GlassIntel newsletter list (monthly pricing updates)
- Re-engage in 90 days with updated data (pending licenses granted, pricing changes)
